# 🌐 Boomika's Portfolio

A modern, responsive, and professional personal portfolio website built to showcase my skills, projects, achievements, and career journey in Data Science and Artificial Intelligence.

## 🚀 About

This portfolio represents my journey as a B.Tech Information Technology student at Chettinad College of Engineering and Technology. It highlights my passion for Data Science, Artificial Intelligence, problem-solving, and continuous learning.

The website is designed with a clean user interface, smooth animations, dark/light theme support, and mobile-friendly responsiveness to provide an engaging user experience across all devices.

* Dark and Light mode support
* Professional introduction section
* About Me and My Story section
